# video_editor

Flutter-based desktop video editor for macOS.

## Getting Started

### Prerequisites

- Flutter SDK
- FFmpeg CLI (includes `ffmpeg` and `ffprobe`)
  - macOS: `brew install ffmpeg`

### Run

```bash
flutter pub get
flutter run -d macos
```

### Notes

- Export/preview/effects use the system FFmpeg binary.
- Manual test checklist: `MANUAL_TESTING.md`
- 手動テスト手順（日本語）: `MANUAL_TESTING_JA.md`

For Flutter basics, see https://docs.flutter.dev/.
