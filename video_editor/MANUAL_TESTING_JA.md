# 手動テスト手順（macOS）

このドキュメントは、アプリの主要機能を一通り確認できる「再現可能な手動テスト手順」です。

## 前提条件

- macOS
- `PATH` 上に `ffmpeg` と `ffprobe` が存在すること
  - macOS: `brew install ffmpeg`
- 依存取得済み: `flutter pub get`

## テスト用メディア

以下を用意してください（短いものでOK）:

- 動画A: 10〜30秒のMP4（音声あり）
- 動画B: 10〜30秒のMP4（音声あり）
- 音声: MP3 または WAV（10〜30秒）
- 画像: PNG または JPG

## 起動

```bash
flutter run -d macos
```

## 1) メディア取り込み

### 1.1 ファイル選択で取り込み

- `Media Library` → `+` からテスト用メディアを複数選択して取り込み
- 期待結果:
  - グリッドにアイテムが表示される
  - 動画/音声の長さが `--:--` ではない
  - 動画アイテムをクリックすると Preview にロードされる

### 1.2 ドラッグ&ドロップで取り込み

- Finder から Media Library パネル上にファイルをドロップ
- 期待結果:
  - ドラッグ中に「Drop files to import」オーバーレイが出る
  - 取り込み件数が増える

## 2) タイムライン編集

### 2.1 トラック追加

- タイムラインのツールバーで以下をクリック:
  - `Add Video Track`
  - `Add Audio Track`
- 期待結果:
  - トラックレーンが表示される

### 2.2 クリップ配置

- Media Library から動画Aを video トラックへドラッグ
- 音声を audio トラックへドラッグ
- 期待結果:
  - クリップが「幅0」ではなく表示される
  - クリップをクリックすると選択状態になり、Properties に詳細が出る

### 2.3 移動（ドラッグ）

- タイムライン上のクリップを別位置にドラッグして配置
- 期待結果:
  - 表示上の開始位置が更新される

## 3) プロパティ（エフェクト/音声/ノイズ除去/トランジション）

### 3.1 エフェクトの追加/削除

- タイムライン上の動画クリップを選択
- `Properties` → `Effects`:
  - プリセットを選んで `Add`
  - ゴミ箱アイコンで削除
- 期待結果:
  - `Applied Effects` の件数が増減する
  - エフェクトがある時だけ `Preview Effects` が押せる

### 3.2 エフェクトプレビュー

- エフェクトを追加した状態で `Preview Effects`
- 期待結果:
  - Preview 右上に「Effect Preview」バッジが表示される
  - プレビュー動画が再生できる
- `Exit Preview` を押す
- 期待結果:
  - 元の動画プレビューに戻る

### 3.3 ノイズ除去（パラメータ）

- 動画クリップを選択
- `Properties` → `Noise Reduction`:
  - 有効化
  - スライダー（Strength / Temporal Radius / Luma / Chroma）を変更
  - Preserve Details を切り替え
- 期待結果:
  - クリップのエフェクトとして低照度ノイズ除去が追加される
  - 変更がクリップに保持される（選択中のクリップに反映され続ける）

### 3.4 トランジション

- タイムライン上のクリップを選択
- `Properties` → `Transitions`:
  - 種類を選択
  - `In` / `Out` を適用
- 期待結果:
  - クリップ上に In/Out の表示が出る

## 4) 再生（タイムラインプレビュー）

- `Preview Quality` プリセットを選択（タイムラインツールバー or Preview の操作部）
- タイムラインの `Play` を押す
- 期待結果:
  - 初回（または Preview Quality を変更した直後）はリアルタイムのストリーミングプレビューが開始される（少し待つ）
  - 現在位置から再生される
  - 再生に合わせてタイムラインの再生ヘッドが進む
- 再生中にタイムルーラー／タイムライン上をクリックしてシークする
- 期待結果:
  - 選択位置付近からストリームが再開し、少し待って再生が再開する
  - 連続再生中は途切れがない（セグメント切り替えによるカクつきが出ない）
- `Stop` を押す
- 期待結果:
  - 再生ヘッドが 0:00 に戻る

## 5) 自動編集 / ハイライト

### 5.1 Auto Edit

- 複数のメディアを取り込んだ状態で、タイムラインの `Auto Edit` を押す
- 期待結果:
  - タイムラインに自動配置される

### 5.2 Generate Highlight

- クリップがある状態で `Generate Highlight` を押す
- 期待結果:
  - 短いハイライト用のタイムラインに置き換わる

## 6) プロジェクト保存/読み込み

### 6.1 保存

- App bar → `Save Project As`
- `.vedproj` を保存
- 期待結果:
  - 保存成功の通知が出る

### 6.2 読み込み

- App bar → `Open Project`
- 保存した `.vedproj` を選択
- 期待結果:
  - タイムラインとメディア一覧が復元される

## 7) エクスポート

- App bar → `Export Video`
- 出力先 `.mp4` を指定
- 期待結果:
  - 進捗ダイアログが 100% まで進む
  - 出力ファイルが作成され、再生できる

## トラブルシューティング

- エクスポート/プレビューが失敗する場合:
  - `which ffmpeg` / `which ffprobe` でパスが返るか確認
  - 出力先ディレクトリに書き込み権限があるか確認
